# Dev-Detective 🔍

A responsive GitHub profile search application built using HTML, CSS, and JavaScript.

## Features
- Search GitHub users by username.
- View profile details and latest five repositories.
- Compare two developers based on repository stars.
- Loading indicators and error handling.
- Responsive design.

## Technologies
HTML5, CSS3, JavaScript, GitHub REST API.

## How to Run
1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Search for any GitHub username.

**Note:** An internet connection is required to fetch GitHub data.
