# AI Prompts Used During Development

AI tools were used for guidance, debugging, and design suggestions during development.

## Prompts Used

### 1. Understanding Requirements

"Help me understand the project requirements and plan the implementation."

### 2. UI and Responsive Design

"Suggest improvements to make the GitHub profile search website responsive and user-friendly."

### 3. GitHub API Integration

"Help me understand how to fetch and display GitHub user details using the GitHub API."

### 4. Debugging

"Help me identify and fix issues in my HTML, CSS, and JavaScript code."

### 5. Feature Implementation

"Help me implement repository listing and compare two GitHub profiles based on their repository stars."

### 6. Documentation

"Help me organize the project documentation and improve the README file."

AI assistance was used as a support tool during development and debugging.
